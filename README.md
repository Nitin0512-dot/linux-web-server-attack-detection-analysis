# Detection 01: Web Server Attack Detection / Web Scanning Detection Using Splunk
# Objective:
The objective of this project is to detect and investigate suspicious web server activity using Splunk.
This project focuses on identifying potential web scanning, directory enumeration, and reconnaissance activity by analyzing HTTP 4xx and 5xx responses.


#Detection 2: Potential Data Exfiltration / Anomalous Data Transfer
# Objective:
Detect potentially anomalous data transfer by looking for client IPs generating a high volume of successful HTTP requests and receiving a large amount of data within a short time window.
